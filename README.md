# Gopiram - Python Developer Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Run locally
1. Extract this ZIP file.
2. Open the `gopiram-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Personalize before publishing
Search the files and replace:
- `YOUR_EMAIL@gmail.com` with your email address.
- `YOUR_PROJECT` with your project repository name.

Your uploaded profile photo is included as `profile.jpg` and is displayed in the homepage hero section. Add your resume link if you want it displayed. Update the email, LinkedIn, and GitHub placeholders in `index.html` before publishing.

## Publish with GitHub Pages
Upload the three website files to a GitHub repository, then go to **Settings → Pages** and deploy from the `main` branch and `/ (root)` folder.
